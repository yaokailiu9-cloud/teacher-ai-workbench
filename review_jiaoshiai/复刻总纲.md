## 一、站点整体结构

整站是一个单页外壳 + 24 个独立工具页的结构：

```
jiaoshiai.top/               首页（工作台入口，三板块聚合）
jiaoshiai.top/#workbench     工作台锚点
jiaoshiai.top/apps/<key>/    24 个独立工具页，各自独立可访问
```

### 1.1 首页分层

| 区块 | 内容 |
|---|---|
| 顶部导航 | 站名「教师AI赋能站 / TEACHER AI WORKSTATION」、积分余额、用户名下拉、注册/登录、积分兑换 |
| 首屏 Hero | 主标题「AI赋能教师提效、教学提分、教培增长。」、副标「教师工作的新基础设施 2026」、主按钮「进入教师工作台」 |
| 板块 01 | **AI赋能教师提效** —— 把备课、资料和课堂制作变成可复用的工作流 |
| 板块 02 | **AI赋能教学提分** —— 围绕审题、解题、得分与错因，建立教学提分闭环 |
| 板块 03 | **AI赋能教培增长** —— 面向家长沟通与续班转化的诊断类工具 |
| 工具卡 | 每卡含：MODULE 编号、计价单位（1 积分/次 或 /张 /5页 /批次）、工具名、一句话定位、一句话说明、「进入工具 ↗」 |

### 1.2 全局系统

- **账户**：用户名 + 密码登录，注册与登录共用一个弹窗（tab 切换），需勾选用户协议。
- **积分**：右上角实时显示余额（当前账号 105 分）。每调用一次生成扣 1 积分，少数工具按量计价（题卷重排 1 积分/5 页、教辅图 1 积分/张、智批作业 1 积分/批次）。
- **兑换码**：所有工具页表单底部都有「兑换码」输入框，占位符格式统一为 `TAI-XXXX-XXXX-XXXX-XXXX`；未登录时显示「立即兑换」按钮。
- **未登录拦截**：直接访问 `/apps/<key>/` 会被重定向到 `/?login=1` 并弹出登录框。

### 1.3 工具页公共骨架

24 个工具页遵循同一套骨架，差异只在字段与结果区：

```
①  顶部导航（积分 / 用户名 / 兑换积分）
②  标题区（工具名 + 一句话说明）
③  输入区（年级、学科 等下拉 + 文件上传 + 补充说明文本域 + 兑换码）
④  生成按钮（文案各工具不同，如「生成试卷」「开始审题分析」「拆解得分点」）
⑤  结果区（分区块的报告结构，多数带 下载 PDF / 下载 Word）
⑥  二次操作（重新生成 / 返回修改 / 组卷 / 去练习）
└─ 无数据时结果区显示占位文案，如「等待生成解题路径」「预习单将在这里呈现」
```

## 四、跨工具的共性规律

1. **输入三段式**：年级/学科下拉 → 文件上传（PDF / DOCX / PNG / JPG，单文件 ≤50MB）→ 补充说明文本域，最后一行固定是兑换码。
2. **题目类工具的三种出题粒度**：相似题 / 变式题 / 综合应用题，数量统一为 1~3 题的三个下拉。
3. **结果区都是「分区块报告」**，典型骨架为：题目预览 → 逐项拆解（3~6 个编号区块）→ 结论/建议 → 导出。
4. **导出统一为 PDF + Word 双通道**，部分额外支持复制结果、组卷、去练习。
5. **生成中状态**：按钮文案切换为进行时并禁用，同时出现「取消」；长任务支持「暂停 / 继续 / 重试未完成的步骤」。
6. **两种计价单位混用**：「次」按调用次数，「张 / 5页 / 批次」按产出量，落地时要区分扣费时机。
